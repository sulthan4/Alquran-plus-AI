# Translations

This directory contains Quran translations in various languages.

## Files Expected:
- `en_sahih.json` - Sahih International (English)
- `en_yusuf_ali.json` - Yusuf Ali (English)
- `ur_jalandhry.json` - Fateh Muhammad Jalandhry (Urdu)
- `ta_baqavi.json` - Baqavi (Tamil)
- `ar_muyassar.json` - Al-Muyassar (Arabic)

## Format:
Each file should be JSON with surah/ayah mapping to translation text.
