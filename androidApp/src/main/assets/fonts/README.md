# Fonts

This directory contains custom fonts for Arabic, Urdu, and Tamil text.

## Files Expected:
- `uthmanic_hafs.ttf` - Uthmanic Hafs font for Quran
- `kfgqpc_hafs.ttf` - KFGQPC Hafs font
- `arabic_naskh.ttf` - Arabic Naskh font
- `urdu_nastaliq.ttf` - Urdu Nastaliq font
- `tamil_unicode.ttf` - Tamil Unicode font

## Sources:
- Fonts should be properly licensed
- Quran fonts from Quran.com or similar sources
