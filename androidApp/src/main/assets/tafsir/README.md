# Tafsir Data

This directory contains Tafsir (commentary) data.

## Files Expected:
- `tafsir_ibn_kathir.json` - Tafsir Ibn Kathir
- `tafsir_tabari.json` - Tafsir al-Tabari
- `tafsir_qurtubi.json` - Tafsir al-Qurtubi
- `tafsir_jalalayn.json` - Tafsir al-Jalalayn

## Format:
JSON with surah/ayah mapping to tafsir text.
