# Quran Data

This directory contains Quran text data in JSON format.

## Files Expected:
- `quran_text.json` - Complete Quran text with Arabic
- `quran_metadata.json` - Surah metadata (names, revelation type, etc.)
- `word_by_word.json` - Word-by-word data with roots and grammar
- `tajweed_rules.json` - Tajweed coloring rules

## Data Sources:
- Tanzil.net
- Quran.com API
- EveryAyah.com
