# Binary Assets Setup

This directory contains assets that need to be manually added because they are binary files (Fonts, Audio, AI Models) and cannot be generated by the AI assistant.

## 1. Fonts
**Location**: `androidApp/src/main/res/font/`

Please download the following Google Fonts (or use your preferred Arabic fonts) and place them here:
- `uthmanic_hafs.ttf` (Required for Quran text)
- `amiri_quran.ttf` (Alternative)
- `roboto_regular.ttf` (Optional, usually system provided)

**Download Link**: [Google Fonts - Amiri](https://fonts.google.com/specimen/Amiri)

## 2. Notification Sound
**Location**: `androidApp/src/main/res/raw/`

- `notification.mp3` - A purely functional sound for Adhan/Reminders.

## 3. App Icon
**Location**: `androidApp/src/main/res/mipmap-*/`

The AI has generated a design for the app icon (`app_launcher_icon.webp`). You should:
1. Use Android Studio's **Image Asset Studio**.
2. Select the generated image as the source.
3. It will automatically generate all the `mipmap` densities (mdpi, hdpi, xhdpi, etc.).

## 4. AI Models
**Location**: `androidApp/src/main/assets/ai_models/`

These files will be needed for the AI features:
- `semantic_search.tflite`
- `speech_recognition.tflite`
